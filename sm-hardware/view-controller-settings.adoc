= Exibir as configurações do controlador no SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Você pode exibir informações sobre um controlador, como o status das interfaces de host, interfaces de unidade e portas de gerenciamento.

.Passos
. No painel esquerdo, selecione menu:Hardware[Controllers and components].
. Execute uma das seguintes ações para exibir as configurações do controlador:
+
** Clique no controlador para exibir o menu de contexto e selecione *Exibir configurações*.
** Selecione o ícone do controlador (ao lado da lista suspensa *Shelf*). Para configurações duplex, selecione *Controller A* ou *Controller B* na caixa de diálogo e clique em *Next*.
+
O menu deslizante de configurações do controlador é aberto.



. Consulte as seções para navegar entre as configurações de propriedades do controlador.
+
.Detalhes do campo
[%collapsible]
====
[cols="25h,~"]
|===
| Secção | Descrição 


 a| 
Detalhes
 a| 
Exibe o status do controlador, data/hora, nome do modelo e número de peça de substituição.



 a| 
Configuração atual
 a| 
Exibe a versão atual do firmware e a versão da NVRAM.



 a| 
Cache de dados
 a| 
Exibe os totais do cache de dados.



 a| 
Módulos de cache de dados
 a| 
Mostra a localização, o status e a capacidade do módulo de cache.



 a| 
Cache do processador
 a| 
Mostra os totais do cache do processador.



 a| 
Dispositivos de backup de cache
 a| 
Mostra a localização, o status e a capacidade do dispositivo de backup em cache.



 a| 
Interfaces de host
 a| 
Exibe informações da interface do host e o status do link para cada porta.



 a| 
Interfaces de drive
 a| 
Exibe informações da interface da unidade e o status da conexão para cada porta.



 a| 
Configurações da porta de gerenciamento
 a| 
Exibe detalhes da porta de gerenciamento, incluindo o nome do host do controlador, login remoto e configurações de rede IP.



 a| 
Configurações do servidor DNS
 a| 
Exibe a configuração de DNS, o servidor DNS primário e o servidor DNS de backup.



 a| 
Configurações do servidor NTP (protocolo de tempo de rede)
 a| 
Exibe detalhes da configuração do serviço NTP e do servidor NTP.

|===
====
. Clique em *Fechar*.
