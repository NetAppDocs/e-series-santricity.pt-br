= Configurar autenticação iSCSI no SANtricity System Manager
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Para segurança adicional numa rede iSCSI, pode definir a autenticação entre controladores (destinos) e hosts (iniciadores).

O System Manager usa o método CHAP (Challenge Handshake Authentication Protocol), que valida a identidade de alvos e iniciadores durante o link inicial. A autenticação é baseada em uma chave de segurança compartilhada chamada _CHAP secret_.

.Antes de começar
Você pode definir o segredo CHAP para os iniciadores (hosts iSCSI) antes ou depois de definir o segredo CHAP para os alvos (controladores). Antes de seguir as instruções nesta tarefa, você deve esperar até que os hosts tenham feito uma conexão iSCSI primeiro e, em seguida, definir o segredo CHAP nos hosts individuais. Após as conexões serem feitas, os nomes IQN dos hosts e seus segredos CHAP são listados na caixa de diálogo para autenticação iSCSI (descrita nesta tarefa), e você não precisa inseri-los manualmente.

.Sobre esta tarefa
Você pode habilitar a autenticação CHAP e, em seguida, especificar o segredo CHAP de destino para autenticação unidirecional, ou pode especificar tanto o segredo CHAP do iniciador para autenticação bidirecional entre o controlador e os hosts iSCSI.

A autenticação unidirecional permite que o controlador autentique a identidade dos hosts iSCSI (autenticação unidirecional).

A autenticação bidirecional permite que tanto o controlador quanto os hosts iSCSI realizem autenticação (autenticação bidirecional). Essa opção fornece um segundo nível de segurança, permitindo que o controlador autentique a identidade dos hosts iSCSI e, por sua vez, que os hosts iSCSI autentiquem a identidade do controlador.

.Passos
. No painel esquerdo, selecione *System*.
. Em *configurações iSCSI*, clique em *Configurar autenticação iSCSI*.
+
A janela Configurar autenticação é exibida.

. Selecione a caixa de seleção *Ativar autenticação CHAP* para ativar a autenticação.
+
Se você não quiser ativar a autenticação CHAP, deixe a caixa desmarcada.

. Se você habilitou a autenticação unidirecional, insira o *Segredo CHAP de destino* para autenticação dos iniciadores que se conectam ao destino. O segredo CHAP deve ter entre 12 e 57 caracteres ASCII imprimíveis.
+
No campo "Confirmar segredo CHAP de destino", insira novamente o mesmo segredo CHAP para confirmá-lo.

. Se você quiser habilitar a autenticação bidirecional entre o controlador e os hosts iSCSI, insira o *Segredo CHAP do Iniciador* para autenticação do controlador pelos iniciadores. O segredo CHAP deve ter entre 12 e 57 caracteres ASCII imprimíveis.
. Clique em *Salvar*.


.Resultados
A autenticação ocorre durante a sequência de login iSCSI entre os controladores e hosts iSCSI, a menos que você não tenha especificado nenhuma autenticação.
