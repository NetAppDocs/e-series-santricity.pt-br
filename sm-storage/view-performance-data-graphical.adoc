= Visualizar dados gráficos de desempenho no SANtricity System Manager
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
É possível exibir dados de performance gráficos para objetos lógicos, objetos físicos, aplicações e workloads.

.Sobre esta tarefa
Os gráficos de desempenho mostram dados históricos, bem como dados em tempo real que estão sendo capturados. Uma linha vertical no gráfico, rotulada Live Updating, distingue os dados históricos dos dados em tempo real.

*Visão do dashboard*

O painel de controle contém um gráfico que mostra o desempenho do array de storage. Você pode selecionar métricas limitadas nesta visualização ou clicar em *Exibir detalhes de desempenho* para acessar menu:Monitoramento[Desempenho] e selecionar todas as métricas disponíveis.

*Vista detalhada*

Os gráficos disponíveis na página de desempenho são baseados nas suas seleções:

* *Tipos de objetos* -- Seleciona as categorias de objetos a serem incluídas (por exemplo, array de storage, controladores, pools e grupos de volume, aplicativos, cargas de trabalho, volumes, canais e unidades).
* *Objetos* — seleciona até cinco objetos específicos para os tipos de objeto selecionados.


.Passos
. Selecione o menu: Monitoramento [Performance].
. Use *Tipos de objeto* e *Objetos* para selecionar os dados que você deseja exibir. Você pode selecionar até cinco objetos; use o campo de pesquisa na lista *Objetos* para encontrar nomes de objetos ou nomes parciais.
+
Nem todas as métricas estão disponíveis para todos os tipos de objeto. Arrays de storage e controladores não reportam latência, apenas controladores reportam utilização de CPU e somente controladores e canais reportam headroom.

. Use *Intervalo de tempo* para selecionar o período que você deseja exibir.
. Clique em *Atualizar*.
. *Opcional:* Em um gráfico individual, use *Comparar* para sobrepor outro tipo de métrica para os mesmos objetos.
. Conforme necessário, use as opções adicionais para visualizar dados de desempenho.
+
.Opções adicionais
[%collapsible]
====
[cols="25h,~"]
|===
| Opção | Descrição 


 a| 
Intervalo de tempo
 a| 
Selecione a duração do tempo que pretende visualizar (5 minutos, 1 hora, 8 horas, 1 dia, 7 dias ou 30 dias). O padrão é 1 hora.


NOTE: O carregamento dos dados de desempenho para um período de 30 dias pode levar vários minutos. Não saia da página da web, não atualize a página da web nem feche o navegador enquanto os dados estiverem sendo carregados.



 a| 
Detalhes do ponto de dados
 a| 
Passe o cursor sobre o gráfico para ver as métricas de um determinado ponto de dados.



 a| 
Barra de deslocamento
 a| 
Use a barra de rolagem abaixo do gráfico para exibir um período de tempo anterior ou posterior.



 a| 
Barra de zoom
 a| 
Abaixo do gráfico, arraste as alças da barra de zoom para diminuir o zoom em um período de tempo. Quanto mais larga a barra de zoom, menos granulares os detalhes do gráfico.

Para repor o gráfico, selecione uma das opções de intervalo de tempo.



 a| 
Arraste e solte
 a| 
No gráfico, arraste o cursor de um ponto no tempo para outro para aumentar o zoom em um período de tempo.

Para repor o gráfico, selecione uma das opções de intervalo de tempo.
