= Novidades no SANtricity OS 12.10
:allow-uri-read: 
:experimental:

[role="lead"]
A tabela a seguir descreve os novos recursos no SANtricity System Manager 12.10.



[[new-features-in-version-12-10]]
== Novidades na versão 12.10

[cols="35h,~"]
|===
| Novo recurso | Descrição 


 a| 
Suporte à expansão SAS para sistemas de storage EF50 e EF80
 a| 
Os sistemas de storage EF50 e EF80 agora suportam expansão SAS, permitindo maior capacidade de storage e flexibilidade. Com a expansão SAS, você pode conectar gabinetes de storage adicionais aos sistemas EF50 e EF80, permitindo que você dimensione seu ambiente de storage conforme necessário. Esse recurso é particularmente benéfico para organizações que exigem soluções de storage de alta capacidade e desejam maximizar o investimento nas plataformas EF50 e EF80.



 a| 
Suporte a NVMe sobre TCP para storage E-Series
 a| 
Os sistemas de storage E-Series agora suportam NVMe sobre TCP, oferecendo uma opção adicional de interface de host para acesso ao storage de alto desempenho. O NVMe sobre TCP permite uma comunicação eficiente e de baixa latência entre o sistema de storage e os hosts conectados, aproveitando os benefícios do protocolo NVMe em redes TCP/IP padrão. Esse suporte aumenta a versatilidade dos sistemas E-Series, permitindo que as organizações os implementem em ambientes onde o NVMe sobre TCP é preferido ou exigido.



 a| 
Melhorias na interface de usuário para o SANtricity System Manager
 a| 
A interface de usuário do SANtricity System Manager recebeu melhorias adicionais para aprimorar a navegação, usabilidade e a experiência geral do usuário. Essas melhorias incluem layout e organização atualizados das tarefas de gerenciamento, além de fluxos de trabalho mais intuitivos para operações comuns de gerenciamento de storage.



 a| 
Suporte expandido para a plataforma E-Series para a nova interface de usuário do SANtricity System Manager
 a| 
A nova interface de usuário do SANtricity System Manager, que foi introduzida na versão 12.00 do SANtricity para os sistemas de storage EF80 e EF50, foi expandida para oferecer suporte a plataformas adicionais de storage E-Series. Isso significa que usuários que gerenciam uma gama mais ampla de sistemas de storage E-Series agora podem se beneficiar da interface modernizada e dos recursos aprimorados de usabilidade. O suporte expandido inclui compatibilidade com modelos selecionados de sistemas de storage E-Series, permitindo que você aproveite a navegação aprimorada e as tarefas de gerenciamento simplificadas em mais partes da sua infraestrutura de storage.



 a| 
Suporte para unidades de desempenho e capacidade mistos para sistemas EF80 e EF50
 a| 
Os sistemas de armazenamento EF80 e EF50 agora suportam unidades SSD NVMe de Performance e de Capacity no mesmo array de storage, desde que haja um número mínimo de unidades (6 para Performance, 12 para Capacity). As unidades de Performance e de Capacity devem permanecer em pools e grupos de volume separados.



 a| 
Aumento do limite de caracteres para nomes de volumes padrão e finos
 a| 
O limite de caracteres para nomes de volumes padrão e finos foi aumentado de 30 para 60 caracteres.


NOTE: Não há suporte para o downgrade para a versão 11.90 ou anterior do software SANtricity OS caso existam volumes padrão ou thin com nomes superiores a 30 caracteres. Se você pretende fazer o downgrade para a versão 11.90 ou anterior do software SANtricity OS, altere os nomes de quaisquer volumes padrão ou thin que possuam nomes com mais de 30 caracteres antes de realizar o downgrade.



 a| 
O tempo limite mínimo de inatividade para a interface de usuário do SANtricity System Manager agora é de 10 minutos.
 a| 
O limite de tempo de inatividade para a interface de usuário do SANtricity System Manager foi atualizado para um mínimo de 10 minutos. Anteriormente, o limite mínimo de tempo de inatividade era de 15 minutos. Essa alteração contribui para aprimorar a segurança, garantindo que a interface de usuário faça logout automaticamente após 10 minutos de inatividade.

|===


[[new-features-in-version-12-0r1]]
== Novos recursos na versão 12.0R1

Esta versão contém apenas pequenas alterações e nenhum novo recurso. Para mais informações sobre as alterações nesta versão, consulte o E-Series SANtricity OS 12.0R1 README.



[[new-features-in-version-12-0]]
== Novidades na versão 12.0


NOTE: A versão 12.0 do SANtricity OS é compatível apenas com os novos sistemas de storage all-flash EF80 e EF50. Se você estiver usando SANtricity OS 11.9 ou anterior, consulte link:known-issues.html["Problemas conhecidos"] para uma lista de novos recursos das versões anteriores.

[cols="35h,~"]
|===
| Novo recurso | Descrição 


 a| 
Novos modelos de sistema de storage – sistemas de storage all-flash EF80 e EF50
 a| 
Esta versão apresenta os sistemas de armazenamento EF80 e EF50 all-NVMe-flash. O EF80 e o EF50 suportam 24 unidades SSD NVMe e uma placa de espelhamento entre controladores por controlador. As interfaces de host NVMe over Fabrics suportadas incluem NVMe over RoCE, NVMe over IB, NVMe over FC para o EF80 e NVMe over FC para o EF50. A interface SCSI suportada é Fibre Channel para ambos os sistemas. O EF50 suporta até duas placas de interface de host por controlador, enquanto o EF80 suporta até três placas de interface de host por controlador.

Unidades SSD NVMe de alta capacidade de 30TB ou 60TB também são suportadas com o EF80 e EF50. O EF80 e o EF50 só podem utilizar Dynamic Disk Pool quando o array estiver populado com unidades de 30TB ou 60TB.



 a| 
Nova interface de usuário para SANtricity System Manager
 a| 
Para os novos controladores EF80 e EF50, a interface de usuário do SANtricity System Manager foi redesenhada para oferecer uma aparência e experiência mais modernas. A nova interface inclui navegação no painel esquerdo e usabilidade aprimorada para simplificar as tarefas de gerenciamento.


NOTE: A nova interface de usuário está disponível atualmente apenas para os sistemas de storage EF80 e EF50 com o lançamento do SANtricity 12.00. Se você estiver usando SANtricity 11.9 ou anterior, consulte link:https://docs.netapp.com/us-en/e-series-santricity-119/system-manager/index.html["Gerenciador de sistemas SANtricity 11,9"] para obter instruções sobre como usar a interface de usuário legada.



 a| 
Subject Alternative Names (SANs) para certificado de servidor agora permitem apenas letras, dígitos e caracteres de hífen
 a| 
Ao criar ou editar um certificado de servidor no SANtricity System Manager ou Unified Manager, o campo Subject Alternative Names (SANs) agora permite apenas letras, dígitos e hífens. Essa alteração aprimora a segurança e garante a compatibilidade com os padrões do setor para certificados SSL/TLS.



 a| 
O tamanho do segmento do Dynamic Disk Pools agora é definido como 32K por padrão para sistemas baseados em SSD e NVMe
 a| 
Para Dynamic Disk Pools em sistemas baseados em SSD e NVMe, o tamanho padrão do segmento foi alterado para 32K. Anteriormente, o tamanho padrão do segmento dos Dynamic Disk Pools era fixo em 128K para esses sistemas. Essa alteração otimiza o desempenho para cargas de trabalho que envolvem uma combinação de operações de E/S pequenas e grandes.



 a| 
Editor de scripts agora disponível no SANtricity System Manager
 a| 
Um novo editor de scripts já está disponível no SANtricity System Manager. O editor de scripts permite criar ou editar um arquivo de script, salvar um arquivo de script no disco local da estação de gerenciamento de storage ou carregar um arquivo de script do disco. O editor de scripts oferece recursos de verificação de sintaxe e execução de comandos para gerenciar seu sistema de storage. Para obter mais informações, consulte link:sm-support/use-script-editor.html["Usando o editor de script"^].

|===
